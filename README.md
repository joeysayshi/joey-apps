## How to install (Mac apps)

1. Download the `.dmg` from the table above.
2. Open the `.dmg` and drag the app into the **Applications** folder.
3. The first time you open it, right-click the app and choose **Open**. These builds aren't notarised yet, so macOS asks you to confirm.
